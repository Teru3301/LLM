# Структура проекта

```
LLM
├── train_ae.py    запуск обучения автоэнкодера
├── run_ae.py      запуск сохранения автоэнкодера
│
├── tokenizer/     тест в вектор эмбедингов и обратно
│   └── ...
├── encoder/       вектор эмбедингов в представление
│   └── ...
├── decoder/       представление в вектор эмбедингов
│   └── ...
├── datasets/
│   └── ...
└── checkpoints/
    └── AE/        сохранения автоэнкодеров
        └── ...
```
