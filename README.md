# Суть проекта

Обучить автоэнкодер и засунуть между енкодером и декодером рекурентную модель. Выход рекурентной модели (вход декодера) должен быть подобным её входу (выходу енкодера) и логичесски представлять собой представление мысли/идеи/сути в момент времени.
Сначала обучается автоэнкодер что бы сформировать состояние, после этого автоэнкодер замораживается, между его частями добавляется рекурентная модель и начаниается обучение для неё.

# Запуск

`autoencoder/{arch}/train_{arch}.py --en= --de= --ch=`
`autoencoder/{arch}/run_{arch}.py --en= --de= --ch=`

`--en=` - имя файла энкодера
`--de=` - имя файла декодера
`--ch=` - имя файла сохранения

Флаги --en и --ch нужны для выбора файлов с другой реализацией но той же архитекстурой (например VAE)
encoder/decoder занимаются только своей задачей, управляют ими run и train. 
train выводит статистику каждые N эпох и делает сохранение текущего состояния каждые M так что бы после остановки можно было продолжить обучени с того же места или запустить ручную проверку.
run запускает сохранение с возможностью ручного ввода текста.
